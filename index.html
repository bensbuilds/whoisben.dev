Under the Hood

This page was built with an iterative, AI-assisted workflow: exploring layouts, typography, colors, and interactions with ChatGPT, then implementing and refining the design in Cursor.

The site uses plain HTML, CSS, and JavaScript, hosted in a private Amazon S3 bucket behind Amazon CloudFront. AWS Certificate Manager provides HTTPS, with DNS managed through Namecheap.

Source code lives in GitHub (opens in a new tab), with Greptile providing automated AI code reviews on pull requests. Changes merged into main trigger a GitHub Actions pipeline (opens in a new tab) that checks required files and JavaScript syntax, publishes the website to S3, refreshes CloudFront’s cache, and verifies the site responds. Deployments authenticate through OpenID Connect (OIDC), assuming an AWS IAM role restricted to the repository and deployment branch, with permissions scoped to the site’s S3 bucket and CloudFront distribution.

Design by ChatGPT, implementation by Cursor, prompts by Ben
